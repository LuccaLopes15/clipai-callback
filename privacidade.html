Política de Privacidade — ClipAI

Última atualização: 19 de setembro de 2026

O ClipAI é uma ferramenta de uso pessoal que roda inteiramente no computador do próprio usuário. Não existe servidor, banco de dados remoto nem serviço hospedado operado pelo ClipAI. Esta página descreve como os dados são tratados.

Quem opera

O ClipAI é mantido por Lucca Lopes para uso próprio, sem fins comerciais e sem distribuição a terceiros. Contato: lopesf.lucca@gmail.com.

Que dados são acessados

Quando o usuário conecta uma conta do TikTok, o aplicativo solicita:

  • user.info.basic — identificador, nome de exibição e foto de perfil;
  • user.info.stats — número de seguidores, de contas seguidas, de curtidas e de vídeos;
  • video.list — a lista dos vídeos publicados pela própria conta, com título, descrição, data, duração, capa, link e os contadores públicos de visualizações, curtidas, comentários e compartilhamentos.

Só são acessados dados das contas que o próprio usuário autorizou explicitamente. O aplicativo não acessa mensagens diretas, rascunhos, vídeos privados, dados de outras pessoas nem qualquer informação além da listada acima.

Onde os dados ficam

Todos os dados são gravados em um arquivo SQLite no computador do usuário. Nada é enviado para servidores do ClipAI, porque não existem. Nada é compartilhado, vendido, cedido ou transmitido a terceiros.

Os tokens de acesso e de atualização do TikTok são armazenados cifrados pela DPAPI do Windows, mecanismo que deriva a chave das credenciais da conta de usuário do sistema operacional. O arquivo copiado para outro computador não pode ser decifrado.

Para que os dados são usados

Exclusivamente para exibir, no computador do usuário, um painel comparando o desempenho dos vídeos das contas que ele mesmo conectou. Não há publicidade, rastreamento, análise de comportamento, perfilamento nem qualquer uso secundário.

Retenção e exclusão

Os dados permanecem no computador do usuário até que ele os apague. Desconectar uma conta no aplicativo remove imediatamente os tokens e o histórico coletado daquela conta. Apagar a pasta do aplicativo remove tudo. O usuário também pode revogar o acesso a qualquer momento nas configurações da própria conta do TikTok.

Menores de idade

O aplicativo não é direcionado a menores de 13 anos e não coleta dados de terceiros.

Alterações

Mudanças nesta política serão publicadas nesta mesma página, com a data de atualização revista no topo.
